# 尼泊尔人物—组织时序图设计规范

版本：0.17.0。此文件记录已经采用的设计规则。新要求的记录见 `requests.jsonl`，落实新要求时同步修改此规范。

## 范围与资料

- 当前案例共呈现26人。大会党批次加入比·普·柯伊拉腊、马·普·柯伊拉腊、克·普·巴特拉伊、吉·普·柯伊拉腊和谢尔·巴哈杜尔·德乌帕。时段扩展为1946—2012年；人物、组织、任职、事件、组织关系、阶段、复合列头和政治背景分别存放在 CSV 表中，以稳定 ID 关联。
- 原有21位共产党人物主要依据汪亭友书内第27—59页的相关叙述，并以导论第4页补记2012年分裂；大会党人物和背景栏为呈现政府轮替与和平进程，另使用本书有关历届政府及对印关系的后续章节。事实表保留 `source_id` 与来源目录，但目前不在图上显示来源。只有用户明确要求时才改变这一展示规则。
- 公开示例和本地数据都保存当前事件对应的书中摘录；人物事件与政治背景节点的悬浮说明优先显示摘录。读入其他资料前先在 `materials/catalog.json` 中登记。
- 用户提供的《尼共毛（汪亭友）前3章.md》是现有扫描书的可检索转写本。第二批人物以该 Markdown 核对姓名、原文和页码；它不作为独立史料重复计数。
- 年份、月份和日期要保留实际精度。只知道年份时，CSV 的 `YYYY-01-01` 是制图占位；说明文字不得把它表述为确切的1月1日。推定任期用虚线和说明标出。
- 1949年4月22日的筹建集会与9月15日党纲发布、正式成立分别成点；书中记载的建党日争议保留在悬浮内容中。未记载具体起止日的党职只据节点或有说明的虚线呈现。

## 图形结构

- 横向是固定组织列，纵向是自上而下的时间。最左列按政权阶段说明实际当权者（国王、首相、执政党或联合政府）及对外关系，重点记录对印关系；任职、公职和党派活动使用对应组织列。
- 人物共用组织列，不按人物数量划分固定子轨。腊伊玛吉的党内事件、党内任职与党外任职合并到同一人物纵线；仅将节点文字分置两侧，不再用左右两条子线区分角色。其他人物仍可按需要使用小幅 `x_offset`。
- 人物使用稳定颜色与标记形状。人物任职线和同一人物跨组织轨迹均为实线，不按日期精度、任期不确定性或支线身份改为虚线；不确定性保留在日期精度和悬浮说明字段中。组织分裂、整党合并、改名、正式另立和共同组建关系用紫色虚线表示；只有部分成员并入时使用紫色点线和“部分并入”标签，表示来源组织或其余派别可能继续存在。组织内部阶段分隔保留横向虚线。
- 事件节点按屏幕位置避让：碰撞的点只沿横向小幅错开，日期坐标不动，标签轮换方向以便分别悬停。人物任职线不绘制端点标记，任职详情在线段上悬停；组织关系只绘制带悬浮信息的紫色虚线，不添加会遮住事件节点的端点菱形。
- 腊伊玛吉谱系中的“腊伊玛吉控制的中央”、尼共（腊伊玛吉）、1983年另立的新党和尼泊尔人民党（社会民主主义）各有真实组织 ID，并在同一组织大列内以阶段名称和横向虚线区分。原书没有记载1983年新党的正式名称，数据和图面明确标为“书中未载党名”，不得用“再次建党”这类动作说明冒充组织名称。
- 组织事实与显示列分离：`organizations.csv` 继续保存真实组织 ID，`organization_lanes.csv` 只决定多个组织在图中是否共用一列。当前除腊伊玛吉谱系外，统一尼共—中央核心小组—四大谱系，以及罗希特、马南达尔、普拉昌达、普拉丹、班达里、纳拉扬·卡吉和大会党谱系也合并显示；具体党名仍由列内阶段标注，数据层不合并。
- 只有前后相承且时间基本连续的组织可共用显示列。并存的Masal／Mashal、两个人民统一战线、1994年后的两个团结中心及2006年后的两个团结中心—Masal仍然分列；同一显示列内部的改名或重组不再重复画零长度紫线。
- 短命组织、单人组织或只承担主谱系分合关系的前身组织可标记为 `lane_type=branch`，通过 `parent_lane_id` 和 `branch_offset` 挂在主列旁边。支线保留真实组织、任职、事件和分合关系，不占用完整列头；任职线用细线，支线名称随关联人物或父级组织列高亮。当前8条支线包括夏尔玛的1999年Masal、尼兰詹·戈文达·维迪亚的1994年人民统一战线、普拉丹等人的1998年尼共（马列主义者），大会党谱系中的尼泊尔民主大会党和国家民主党，以及2006年四路分裂中的尼泊尔共产党（2006）、什里斯派转入的尼共（统一）和2012年分出的尼共—毛。后三者在当前人物表没有可直接绑定的成员任职时，只显示组织阶段与关系，不补造人物轨迹。没有明确分裂来源或具有长期独立政治作用的组织不自动改成支线。
- 新增组织列后画布按主列数横向扩展，列头显示书中的党名简称，不自行缩为“尼共（腊）”“尼共（统大）”“尼共（联马列）”或单独的“Masal”“Mashal”；支线不增加列头，画面可横向滚动，不以人物数量分割同一党派的固定子列。
- 主列从左到右先放背景栏和统一尼共—中央核心小组—四大谱系；其后紧邻放置原在图末的六条相关主列，顺序保持为尼共（Masal）、尼共（Mashal）、纳拉扬·卡吉谱系、普拉昌达谱系、人民统一战线、辛格派尼共（团结中心—Masal）。腊伊玛吉、马南达尔、布尔玛、统一大会、阿玛提亚、普拉丹、罗希特、班达里和联合马列谱系依次后移，大会党固定为最右主列。所有支线随父级主列移动。
- 1962年三大至1968年第二次大分裂之间，普什帕·拉尔·什雷斯塔与吐尔西·拉尔·阿玛提亚仍放在统一尼共列：阿玛提亚任总书记，二人共同分担全党领导。1968年什雷斯塔另立尼共（普·拉）后，阿玛提亚领导的原组织才以尼共（阿玛提亚）单列；不得把这一派名提前到1962年。1994年后普拉昌达另立的同名“尼共（团结中心）”与后来同辛格的Masal合并的原组织分开；2006年辛格另立的同名“尼共（团结中心—Masal）”亦分开。相同的书中党名可以重复显示，另用较小的“组织识别”文字说明分支，稳定组织 ID 和分合线不混接。
- 统一尼共、1971—1973年的尼共中央核心小组和1974—1990年的尼共（四大）共用“尼共谱系”显示列，以三个阶段名称和横向虚线区分。核心小组试图恢复历史上统一的尼共，四大则以党名表明延续前三次代表大会；这只是谱系合并显示，三个真实组织 ID 及其事件、任期和分合事实保持独立。
- 班达里谱系依次列出解放阵线团体、全尼泊尔共产主义革命协调委员会（马列主义者）和尼共（马列）。材料只明确解放阵线于1977年并入协调委员会，以及班达里在1986年尼共（马列）四大当选总书记；因此1986年只作为绘图阶段边界并标记为不确定，不得表述为已查明的改组或建党年份。
- 尼共（四大）在1990年的解体保留两条“部分并入”关系：大部分成员并入Mashal，较小部分后来参加尼共（团结中心）。不得只画后一条而遗漏多数去向，也不得把任一支写成四大整体合并。
- 团结中心—Masal在2006年分为四路：辛格派另立同名组织，加瓦·库马尔一派成立尼泊尔共产党（2006），拉姆·辛格·什里斯一派加入尼共（统一），纳拉扬·卡吉·什雷斯塔一派保留原名。四路使用独立组织 ID，两个材料较少的小派作为支线。
- 统一尼共（毛）在2012年6月分裂，普拉昌达领导的组织保留原名，分出组织记为尼泊尔共产党—毛主义者（尼共—毛）支线。当前采用的材料段落没有点名分裂派领导人，故只把关系与事件关联到该段明确点名的普拉昌达，不据常识把莫汉·维迪亚或其他人物轨迹接入。
- 尼泊尔人民统一战线是政治阵线而非共产党本体。1991年初由团结中心联合尼泊尔工农组织和尼共（马列毛）创建，后两者退出后，巴特拉伊于8月17日重建；两段在同一真实组织下作为独立阶段显示。1995年该阵线同普拉昌达派“共同组建”尼共（毛），不用“合并”暗示两个共产党整党合流。
- 每个包含多个组织或实质阶段的主列都使用复合列头。`organization_lane_headers.csv` 按 `header_order` 保存从早到晚的 `stage_id` 或 `org_id` 引用，不重复保存名称和年代；程序从阶段表或组织表解析显示内容，并校验引用存在、属于同一主列、起始年代递增且每个引用只出现一次。每个条目显示横排名称和较小的年代范围，条目总体纵向排列并以向下箭头连接。箭头只表示时间顺序与谱系归类，不必然表示直接改名、合并或无间断继承；正式分合事实仍只由 `organization_relations.csv` 表达。每列必须且只能以 `is_primary=yes` 标记一个代表性组织，渲染时用粗体显示。大会党列按三个真实组织列名，不把同一大会党的政治阶段重复当作不同组织；单一组织列不使用复合列头。

## 交互

- 默认聚焦普拉昌达，其余人物及未关联信息以20%不透明度淡显；点击“全部人物”时所有人物以20%不透明度显示。左侧政治背景继续保持单独的原有虚化，不随人物或组织聚焦变为高亮。
- 可点击图顶端的组织列名、列内空白色带或使用右侧组织下拉框聚焦一列。列内色带全高用于提示可选区域；点击选择按鼠标在绘图区的位置与当前横轴范围计算列号，不依赖填充轨迹是否发出 Plotly 点击事件。按下事件限定在图表内，松开事件在页面级捕获，以免 Plotly 临时拖拽覆盖层吞掉松开；按下与松开位置相差超过5像素视作拖动，不触发列选择。人物节点、任职线和组织关系线命中时优先执行其自身交互。选择组织列后，曾在该谱系任职或留下事件的人物及其个人轨迹为60%；选中或悬停的人物优先级更高，为100%；其余人物为20%。属于该列的组织关系、阶段线、阶段名称及所挂支线也为60%，若同时关联当前聚焦人物则为100%。组织选择与人物选择可叠加。
- 右侧说明按任务顺序写成完整使用指南，分别说明查看人物、比较人物、查看组织谱系、组合查看、避免误选和恢复显示；另设图例说明人物线、组织关系线、阶段线和复合列头。界面状态使用“重点人物”“临时查看”“已选组织谱系”等自然语言，不把“100%／60%／20%”直接当作操作名称。透明度只表示当前筛选下的视觉关注程度，不代表人物的历史重要性、组织规模或史料可信度。
- 人物节点或人物线用于选择人物；紫色组织关系线只用于悬停阅读分合详情，点击关系线仅阻止误选其后的整列，不另行改变筛选状态。选择整列应点击列名、列内空白色带或使用组织下拉框。
- 页面向下滚动越过原列头后，窗口顶部显示与 Plotly 横轴同步的固定列头；它使用同一份名称、年代、粗体和箭头数据，并根据页面横向滚动、窗口大小及 Plotly 横轴缩放重新计算位置。滚出图表底部后固定列头隐藏。
- 悬停人物节点或任职线时，其全部事件、任职、组织关系和阶段标注同步按100%显示；其他人物按当前组织选择显示60%，否则为20%。
- 单击锁定聚焦；再次单击取消。Shift＋单击或右侧比较模式可同时聚焦最多3人。人物搜索用于定位。按 Esc 恢复默认聚焦普拉昌达、清除组织选择、清空搜索、关闭比较模式并恢复图表初始缩放与页面起始位置；点“全部人物”取消人物聚焦但保留选中的组织列。
- 右侧固定显示使用说明。鼠标悬浮事件节点展示该事件的书中摘录；摘录缺失时才展示简要描述。悬浮框统一区分“党内任职”“政治阵线任职”“政府任职”“组织事件”和“政府事件”；腊伊玛吉沿用“党外任职”表述。王室剧变、政治生涯结束及去世等非任职节点另作准确分类。组织列仅供定位，政府职务的悬浮框不把所在党列误写为任职机构。
- `related_person_ids` 用分号关联一人或多人。聚焦其中任何一人时，该组织分合线或对应阶段标注高亮；不同谱系、不同阶段分别计算透明度，不因某一谱系命中而使全部阶段同时高亮。未建人物轨迹的对方组织不自动推定为某位人物。
- 高亮使用一次批量更新人物与组织关系线；阶段线和名称的透明度随同一聚焦状态更新，避免逐条重绘。
- 政治背景的所有时间段合并为一条带断点的 Plotly 轨迹；同一人物、同一类型的跨组织短连接也合并为一条带断点的轨迹。两者都保留逐段悬浮内容，以减少人物扩展后的浏览器重绘数量。

## 当前案例的关键标注

- 阿迪卡里1954年任总书记；1957年缺席尼共二大。书中写明他1961年因反对无党派评议会制度入狱9年，未注明入狱月份。
- 腊伊玛吉的1954年节点承载其出生、早年赴印、1947—1948年组织活动和1954年进入尼共中央的叙述；终点为2012年去世。
- 什雷斯塔的轨迹从1949年筹建尼共至1978年去世；辛格包括大会党、早期尼共、中央核心小组、尼共（四大）、Masal与2002年团结中心—Masal；普拉昌达从1977年加入四大，经Masal、Mashal和团结中心，至1995年改名尼共（毛）。首次人物节点可承载其出生、求学等早年背景，不把出生年误作党派任期。
- 第一批扩展补齐四条直接相关的组织链：腊伊玛吉派经马南达尔、布尔玛等分支至尼共（联合），其中只有布尔玛派和阿玛提亚派的一部分在1993年转入联合马列，马南达尔一线继续沿用尼共（联合）名称至2005年；普什帕·拉尔派经解放阵线、革命协调委员会、尼共（马列）或尼共（马）至尼共（联合马列）；尼共（四大）经Masal、Mashal至尼共（团结中心）；巴特拉伊经尼泊尔人民统一战线参与共同组建尼共（毛）。莫汉·维迪亚与巴特拉伊相关段落中的尼兰詹·戈文达·维迪亚不是同一人，数据和悬浮文字不得混同。
- 1962年瓦腊纳西三大开除腊伊玛吉后，阿玛提亚与什雷斯塔共同领导的组织仍记作统一尼共；1968年什雷斯塔带领大部分骨干另立尼共（普·拉），阿玛提亚领导的原组织此后才称尼共（阿玛提亚）。
- 第二批扩展补齐尼共（普·拉）至尼泊尔工农组织／工农党、尼共中央核心小组、夏尔玛的Masal分支、尼兰詹·戈文达·维迪亚另立的人民统一战线，以及团结中心—Masal并入统一尼共（毛）的路径。尼兰詹·戈文达·维迪亚、莫汉·维迪亚、尼兰詹·查帕金是三个不同人物；本轮不把查帕金在尼共（四大）的活动误接给前两人。
- 大会党谱系从1946年全印尼泊尔国民大会党起步，经1947年改组、1948年尼泊尔民主大会党分出、1950年两党共同合并成立大会党、1960年党禁、1990年恢复多党制及2006年七党联盟时期。1950年关系必须同时从尼泊尔国民大会党和尼泊尔民主大会党指向大会党，不能只保留后者。马·普·柯伊拉腊另组的国家民主党和尼泊尔民主大会党均作为支线；比·普·柯伊拉腊、马·普·柯伊拉腊、克·普·巴特拉伊、吉·普·柯伊拉腊和德乌帕的党职与政府职务在同一大会党谱系中呈现，但悬浮框明确区分性质。
- 分裂对方或拒绝加入某组织的事件放在当事人当时所在的组织列；跨组织的关系另用紫色分合线表示。人物节点所在列不可暗示书中未记载的入党或任职。
- 原书未给出部分王室或政府职务的精确任期，应用事件点或虚线呈现，不补造具体日期。

## 项目边界与版本

- 图表输入和输出路径必须在项目根目录内。公开仓库只追踪代码、规范、目录和可公开的结构化示例。
- `materials/local/` 存放原始 PDF 与本地数据副本，`output/` 存放可重建的 HTML，两者均不提交到 Git。事件摘录存放在可版本化的示例 CSV 中。
