# 尼泊尔五位人物的组织时序图示例

这一组 CSV 保留组织、人物、任期、事件、政治背景与组织关系的结构化信息。`source_id` 通过 `sources.csv` 指向汪亭友书内页码；`source_excerpt` 保存对应事件的书中摘录，供公开图的悬浮说明使用。扫描 PDF 存放在 `materials/local/`，不随仓库上传。

目前包含阿迪卡里、腊伊玛吉、普什帕·拉尔·什雷斯塔、莫汉·比克拉姆·辛格和普拉昌达。新增三人的资料限于书内第60页之前；1949年建党日争议及1994年后同名“团结中心”的分支在表中分开记录。

`organization_relations.csv` 和 `organization_stages.csv` 的 `related_person_ids` 支持用分号关联多人。选中关联人物时，对应的组织分合线、阶段分隔线和名称一起高亮。
