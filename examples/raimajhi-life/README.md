# 尼泊尔二十六位人物的组织时序图示例

这一组 CSV 保留组织、人物、任期、事件、政治背景与组织关系的结构化信息。`source_id` 通过 `sources.csv` 指向汪亭友书内页码或外部核对资料；`source_excerpt` 保存对应事件的资料说明，供公开图的悬浮说明使用。扫描 PDF 存放在 `materials/local/`，不随仓库上传。

目前包含26位人物。大会党批次新增比·普·柯伊拉腊、马·普·柯伊拉腊、克·普·巴特拉伊、吉·普·柯伊拉腊和谢尔·巴哈杜尔·德乌帕。原有21位共产党人物主要依据书内第60页以前内容，并以导论第4页补记2012年分裂；大会党人物另使用本书关于1990年民主转型、历届政府及和平进程的相关章节。1949年建党日争议、同名组织的不同分支及近似人名均分开记录。

`background_events.csv` 以64个首尾相接的时期连续覆盖1949年4月22日至2012年12月31日。每段明确政体、国家元首、政府首脑、主要执政组织、联合执政成员、阁外支持者、政府性质、上下台依据及对印关系；`political_entities.csv` 为王室、政党、联盟和其他政治集团提供稳定引用，不把它们自动增加为人物组织列。

1962年瓦腊纳西三大至1968年第二次大分裂之间，普什帕·拉尔·什雷斯塔和吐尔西·拉尔·阿玛提亚仍归入统一尼共；1968年什雷斯塔另立尼共（普·拉）后，阿玛提亚领导的原组织才记作尼共（阿玛提亚）。

`organization_relations.csv` 和 `organization_stages.csv` 的 `related_person_ids` 支持用分号关联多人。选中关联人物时，对应的组织分合线、阶段分隔线和名称一起高亮。

`organization_lane_headers.csv` 只保存复合主列顺序、`stage_id`／`org_id` 引用和主要组织标记，不重复保存名称与年代。程序从 `organization_stages.csv` 或 `organizations.csv` 解析名称与年代，并校验引用对象属于同一主列、起始年代按顺序递增。每列名称和年代按时间向下排列并用箭头连接，`is_primary=yes` 的代表性组织以粗体显示；箭头只表示时间顺序与谱系归类，不必然表示直接改名或合并。大会党只列三个真实组织名称，不重复列出同一组织的政治阶段。

`organizations.csv` 保存41个真实组织，`organization_lanes.csv` 将其中具有连续领导和继承关系的组织映射为共同主列。腊伊玛吉控制的另一中央、尼共（腊伊玛吉）、1983年另立但书中未载党名的新党和尼泊尔人民党（社会民主主义）分别使用真实组织 ID，但继续共用腊伊玛吉谱系列。统一尼共、尼共中央核心小组和尼共（四大）共用尼共谱系列；解放阵线团体、全尼泊尔共产主义革命协调委员会（马列主义者）和尼共（马列）共用班达里谱系列；大会党的前身和后续阶段共用大会党主列。公开图使用18条主列，另有8条支线；支线新增2006年四路分裂中的尼泊尔共产党（2006）、什里斯派转入的尼共（统一），以及2012年分出的尼共—毛。悬浮框和关系数据仍显示具体组织名称。

主列顺序将统一尼共—四大之后的六条相关谱系直接放在尼共谱系右侧，依次为Masal、Mashal、纳拉扬·卡吉谱系、普拉昌达谱系、人民统一战线和辛格派团结中心—Masal；腊伊玛吉等列依次后移，大会党及其支线放在最右端。

关系表以 `partial_merge` 区分“部分并入”和整党合并；四大在1990年分别记录大部分并入Mashal与较小部分参加团结中心，尼共（联合）也只把布尔玛派和阿玛提亚派的一部分接入联合马列。人民统一战线记录1991年初建与8月17日重建两个政治阵线阶段，它与普拉昌达派是共同组建尼共（毛），不是两个共产党整党合并。大会党1950年的成立则同时保留两个来源组织的合并关系。
