# 尼泊尔二十六位人物的组织时序图示例

这一组 CSV 保留组织、人物、任期、事件、政治背景与组织关系的结构化信息。`source_id` 通过 `sources.csv` 指向汪亭友书内页码；`source_excerpt` 保存对应事件的书中摘录，供公开图的悬浮说明使用。扫描 PDF 存放在 `materials/local/`，不随仓库上传。

目前包含26位人物。大会党批次新增比·普·柯伊拉腊、马·普·柯伊拉腊、克·普·巴特拉伊、吉·普·柯伊拉腊和谢尔·巴哈杜尔·德乌帕。原有21位共产党人物主要依据书内第60页以前内容；大会党人物另使用本书关于1990年民主转型、历届政府及和平进程的相关章节。1949年建党日争议、同名组织的不同分支及近似人名均分开记录。

1962年瓦腊纳西三大至1968年第二次大分裂之间，普什帕·拉尔·什雷斯塔和吐尔西·拉尔·阿玛提亚仍归入统一尼共；1968年什雷斯塔另立尼共（普·拉）后，阿玛提亚领导的原组织才记作尼共（阿玛提亚）。

`organization_relations.csv` 和 `organization_stages.csv` 的 `related_person_ids` 支持用分号关联多人。选中关联人物时，对应的组织分合线、阶段分隔线和名称一起高亮。

`organizations.csv` 保存34个真实组织，`organization_lanes.csv` 将其中具有连续领导和继承关系的组织映射为共同主列。大会党的前身和后续阶段共用原有大会党主列；尼泊尔民主大会党、国家民主党及原有三个短命组织作为支线挂在主列旁。公开图因此仍使用20条主列，另有5条支线；悬浮框和关系数据仍显示具体组织名称。
